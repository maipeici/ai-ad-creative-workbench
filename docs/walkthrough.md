## 跟着视频完成一个项目

| 时间 | 操作 | 为什么做这一步 |
| --- | --- | --- |
| 0:00 | 新建素材项目 | 给本次广告单独命名，需求、创意、分镜和产物都会保存在同一项目中。 |
| 0:07 | 选择事实与素材 | 选用一键叫车等已确认事实，选择人物、服装、车辆、场景，以及库中已有的界面和 Logo。 |
| 0:25 | 填写投放需求 | 设置抖音、通勤人群、下班返程、15 秒、立即叫车；明确不使用优惠金额或免等待承诺。 |
| 0:39 | 生成并选择创意 | 生成两种方向，选择“告别晚高峰”，将卖点落实到已确认的产品功能。 |
| 0:53 | 拆解分镜与生成首帧 | 生成三个 5 秒镜头，检查口播、字幕、人物和场景，再生成各镜头预览图。 |
| 1:14 | 自动审核、修改与复检 | 审核发现安全区方案不够具体和免等待暗示。补充坐标约束、修正文案及创意卡片，再运行原清单直到全部通过。 |
| 2:00 | 生成真实视频镜头 | 用首帧图提交三个 Veo 图生视频任务。模型每镜生成 6 秒，后期按分镜裁到 5 秒。 |
| 2:10 | 叠加与合成 | 为镜头加入字幕、现有品牌素材与中文配音，逐镜播放确认，按顺序合成。 |
| 2:34 | 播放并下载 | 在工作台播放器检查结果，点击“下载成片”获得 MP4。 |
| 2:43 | 观看实际成片 | 录屏结尾附此次生成的完整广告和原音轨。 |

## 此次实际产出

- 三个镜头各约 5 秒，成片约 15 秒，1080 × 1920 竖屏。
- 三个镜头均有烧录字幕与中文配音；产品镜头叠加已有界面素材，结尾镜头叠加已有 Logo。
- [演示成片（720p 压缩展示版）](../assets/demos/workflow-result.mp4)。工作台下载的是本次 1080p 合成文件。
- 创意与分镜使用 Gemini 2.5 Pro，首帧使用 Gemini 2.5 Flash Image，镜头使用 Veo 3.0 Fast，配音使用 Cloud TTS，后期使用 FFmpeg。

操作画面采用文字讲解；结尾的成片展示保留其原音轨。生成画面的动作、一致性和素材版本仍需要正式投放前复核，自动审核阶段只校验文本、引用与制作方案。

## 在自己的环境复现

1. 按 [部署说明](deployment.md) 启动工作台，并按 [模型配置](configuration.md) 配置模型、Cloud TTS 和 FFmpeg。
2. 新建项目，准备自己的品牌事实、Logo 和产品界面素材，再按录屏顺序操作。
3. 根据审核依据修改实际问题，复检通过后生成镜头；模型调用耗时与费用取决于配置和用量。
4. 播放生成结果并下载。模型输出具有随机性，复现时不会得到完全相同的画面。

项目运行数据和私有上传素材仍保存在本地，不随仓库分发；本页只发布专门录制的演示及其成片。无需配置模型的页面熟悉方式见 [12 步气泡导览](guide.md)。
