# 批量制作、自动审核与素材测试

## 一条创意，多个视频版本

1. 新建项目，从「品牌素材」开始，直接选择、新增或编辑品牌。五个板块分别管理品牌基础信息、营销活动、品牌素材资源、视觉设计、合规边界说明。
2. 在投放需求确定平台、人群、场景、转化事件、活动和交付目标。整批共享这些输入。
3. 在广告创意中比较候选方向，选定本项目的一条核心创意。新方向应另建项目。
4. 在分镜规划完成基础脚本，再设置共用钩子、其他固定要求、允许变化项和版本总数（2–60，含基础版本）。镜头顺序、时长、卖点依据、品牌素材和 CTA 保持固定。通过顶部「版本脚本」准备脚本，并切换版本查看或编辑。
5. 在「视频制作」批量生成镜头，自动加入字幕、品牌素材与配音，再合成完整视频。生成前只做本地基础检查，单条失败不影响其余版本，可暂停和续作。
6. 在「自动审核」统一检查实际成片，查看问题时间段及修复建议。修复并重新合成后复检，通过的版本直接在该页打包下载。镜头级设置留在视频制作详情中。

原项目的分镜和视频保留为基础版本，新增版本不会覆盖它。旧版混合多个创意的项目会先备份至本地 data/runtime/backups，再按创意拆为独立项目，保留所有素材 ID、脚本、媒体地址和实验引用。已建立版本的创意与框架固定，新增版本沿用快照；已有历史脚本保持原样。共享品牌、需求或事实变化会使受影响的审核及成片待更新。单条自动修复不改变整批事实选用，需要调整共用资料时会提示。

暂停保留已完成内容，已提交的远程任务可能继续执行。重启服务后本地队列显示暂停，需要再次选择并启动；已有远程镜头继续查询进度。示例分镜不计为真实生成完成。完整合成需要可用的 FFmpeg。

## 先制作，再统一审核

| 环节 | 检查对象 | 目的 |
| --- | --- | --- |
| 生成前基础检查（自动执行） | 脚本完整性、明确阻断项与素材就绪 | 生成前发现不可执行的问题，无独立审核页面 |
| 自动审核 Agent | 实际成片、品牌与平台规则、创意与项目要求 | 统一审核；通过后在同页打包下载 |

品牌要求集中在「合规边界说明」维护，平台规则按投放渠道载入。审核页显示来源、结果和建议，项目特有要求可在折叠区补充。品牌、平台及制作检查均满足才能通过；缺少规则或证据时显示待补充。

内置抖音、腾讯广告和快手规则为附公开来源的基础条目，未覆盖全部行业、版位、资质和落地页。腾讯部分来源为历史官方培训资料；微信视频号暂未内置规则。按实际场景补充规则正文、HTTPS 官方来源和版本。规则不是实时同步，工作台通过不等于平台最终审核通过。

成片自动审核使用 Vertex Gemini，支持不超过 14 MB 的本地视频；失败保留成片，不自动重做收费镜头。交付 ZIP 包含视频、可用封面、文案 TXT、元数据及质检状态，整包最多 250 MB。过期成片不可作为当前成果导出；未审核或未通过的成片不可打包；通过版本可先行打包，不必等待整批通过。

## 素材测试：四步完成

已有当前成片后，从「自动审核」页的「进入素材测试」进入。需求、创意和分镜阶段专注制作准备。

1. **选素材**：直接选择已有当前成片，不复制整个项目。
2. **定问题**：选择多素材对比或单变量测试，填写问题和主要指标。
3. **导数据**：下载 CSV 模板，填写实际数据并上传或粘贴。
4. **看结论**：查看主指标与描述性差异，记录结论、下一轮建议，可带入新任务。

多素材对比至少两条，适合观察整体创意差异。单变量测试可先选一条 A 基准片，再创建仅改首镜头内容或末镜头行动引导的版本；固定镜头直接复用原视频。需求、引用、时长、全局内容及固定镜头必须一致，否则改用多素材对比。单变量改写最多 6 个版本；选择已有素材最多 12 条。

变量单位为一个镜头的内容，可能同时包含画面和文案，不能证明哪个字或画面细节造成差异。工作台检查创作一致性，实际人群、预算、归因和分流在广告平台设置。实验版关闭跨镜头自动修复；固定内容有误应先修改源素材再建立测试。

## CSV 字段和口径

| 字段 | 含义 |
| --- | --- |
| `version` | A/B/C 等标签或素材 ID |
| `startDate`, `endDate` | YYYY-MM-DD，含首尾日期 |
| `impressions`, `clicks`, `conversions` | 曝光、点击、点击归因的去重转化数量，非负整数 |
| `spend` | 消耗，人民币元，非负数 |
| `source` | 平台、广告组或导出批次，不填凭证 |

全部必填，转化数不超过点击数、点击数不超过曝光数。当前模板不支持浏览归因或一次点击多次转化。[空白模板](../assets/examples/experiment-results.csv)。

- 同版本、同区间重新导入覆盖原记录；重叠但不同区间被拒绝。
- 只有当前有效成片可关联结果；演示占位、过期或缺失版本不可导入。
- CTR = 点击 / 曝光；CVR = 转化 / 点击；CPA = 消耗 / 转化。分母为零显示「—」，不把缺数据当 0。
- 各版本需有相同区间、有效主指标、正曝光且对应当前成片，才可作描述性比较。不自动判断胜出、显著性或因果关系。
- 尚未接入广告账户发布、自动效果回传、预算执行或多租户权限。
