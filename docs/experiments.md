# 推广任务、素材实验与交付

## 从可复用资料开始

在侧栏「资料中心」维护品牌档案，并在品牌基础信息、营销活动、品牌素材资源、视觉设计、合规边界说明五个板块中选择常用素材和已确认事实。新任务继承默认选用；已有任务不会被新默认值覆盖。修改共享事实、实际引用素材或品牌规范，会使相关审核需要复检；新增无关资料不会影响已有审核。

新任务直接进入「投放需求」。选一个主要转化事件，关联营销活动，补充承接页面、计划交付数量和日期。数量与日期用于记录需求，不会自动创建投放计划或批量生成任务。离开需求页时会保存修改，保存失败则保留当前页面。爆款参考统一从参考库选用，旧参考文字仍保留。

分镜默认显示中文画面、口播、字幕和时长；模型提示词、镜头参数与全局锁定说明放在高级设置中。

## 建立 A/B 素材实验

1. 在源任务选定创意并生成基准分镜，再打开「实验复盘」。
2. 填写实验假设、主指标、固定人群、预算分配、时间与归因口径。目前支持测试**首镜头内容**或**末镜头行动引导**，每组最多 6 个版本。
3. 保存实验后生成独立 A 版快照。先完成 A 版的镜头制作和合成；已有的基准成片可以沿用。
4. 手动或通过 AI 改写指定镜头，建立 B 版。其他镜头直接复用 A 版的已合成视频。需求、时长、人物引用、全局描述、模型参数和音色保持锁定。创建 B 版后，A 的视频也锁定。
5. 打开 B 版，修改指定镜头并完成脚本预检、视频制作、成片质检。实验内不进行跨镜头自动修复；固定内容有问题时，应返回源任务修改后建立新实验。
6. 下载独立版本或整组 ZIP，在广告平台设置真实的投放、预算和分流。

这里的变量单位是一个镜头的创意内容，可同时包含该镜头的画面与文案；它不能进一步证明是哪一个字、字幕或画面细节造成效果变化。工作台锁定创作内容，不能保证实际投放的人群、竞价和分流条件相同。

## 导入同口径结果

从实验页下载 CSV 模板，按模板整理广告后台数据。字段如下：

| 字段 | 含义 |
| --- | --- |
| `version` | A/B/C 等版本标签，或该版本的项目 ID |
| `startDate`, `endDate` | 统计起止日期，格式 YYYY-MM-DD，含首尾日期 |
| `impressions`, `clicks`, `conversions` | 曝光、点击、点击归因的去重转化数量，非负整数 |
| `spend` | 消耗，人民币元，非负数 |
| `source` | 数据来源，例如平台、账户、广告组与导出批次，勿填写凭证 |

所有字段必填。当前模板不支持浏览归因或一次点击多次转化，要求转化数不超过点击数。记录归因窗口，并保证两版采用相同平台口径。模板示例在 [assets/examples/experiment-results.csv](../assets/examples/experiment-results.csv)，只有空白字段，不含虚构成绩。

- 同版本、同区间重新导入会覆盖原记录，不累计两次；重叠但不同的区间会被拒绝。
- 只有已制作成片的版本可以关联结果。演示占位视频、过期成片和缺失版本不可导入。
- CTR = 点击 / 曝光；CVR = 转化 / 点击；CPA = 消耗 / 转化。分母为零时显示「—」，缺数据与 0 分开显示。
- 各版本需有相同统计区间、且结果对应当前成片，才提示可作描述性比较。系统不自动判断胜出、显著性或因果关系，也不验证广告后台实际执行的分流。
- 保存结论与下一轮建议，点击「带入下一轮创作」建立新任务，继承需求和复盘文字；原实验保留。

## 分开检查脚本与视频

「脚本预检」检查生成前的创意、分镜和引用；「成片质检」把实际视频字节传给 Vertex Gemini，检查画面、声音、字幕、事实一致性和节奏，返回时间位置、依据与修改建议。当前成片质检支持不超过 14 MB 的本地视频，不会自动重生成收费镜头。模型缺失或结果不完整时保持待处理。

修改脚本或镜头后，旧成片仍可回看，但会标记待更新，相关质检不能沿用。视频交付包包含 MP4、可用封面、文案 TXT 和元数据 JSON；实验整组包还包含实验设计与结果记录。JSON 创作数据导出继续保留。

质检不等于媒体审核。ZIP 如实记录质检状态，尚未通过质检的当前成片也可下载供协作排查；过期成片不可作为最新交付包导出。本项目尚未接入广告账户发布、自动效果回传、预算执行或多租户权限。
